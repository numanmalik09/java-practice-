 Java Practice 

This repo is my daily coding journal  a collection of small Java programs I write and upload almost every day as I learn.

Why this repo exists

I started my BCA in July 2026, and my goal is simple: become a strong software engineer and eventually work at a top MNC like Google or Microsoft. I know that goal doesn't come from just attending lectures it comes from writing code every single day, even if it's something small.

So instead of letting my practice programs sit forgotten on my laptop, I decided to push them here. Some days it's a simple calculator, other days it's a logic problem I struggled with for an hour before it finally clicked. Either way, it goes here.

 What you'll find

- Beginner-level Java programs (loops, conditionals, basic logic)
- Small utility tools (converters, calculators, checkers)
- Console-based mini projects as I build up to bigger ones

Every file is a snapshot of where I was on that day of learning. Some are rough, some are polished  that's intentional. I'd rather show honest progress than a fake "perfect from day one" portfolio.
